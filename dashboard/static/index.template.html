Share of the shock-attributable decline assigned to the payment suspension, under the assumption set currently selected. A hollow bar means the two channels came out with opposite signs, so the split is not a partition and only the percentage-point figures are meaningful.

Sensitivity to the two identifying knobs

Estimates are conditional on the assumption set shown beside them, and several of those assumptions fail outright on this data — conditional stationarity across an invasion, and exogeneity of macro controls that the same sanctions package moved. The models are run anyway, with the failure labelled, because a bounded and labelled estimate is more useful than silence. Read the spread, not any single figure.
